- upstream `/proprietary` assets;
- assets hosted only on OpenFront production/CDN infrastructure;
- premium skins/models/textures;
- proprietary sound/music fetched from OpenFront APIs;
- private OpenFront APIs or production services.

Replacement branding and other fork-specific assets must be original or carry a compatible redistributable license with attribution recorded here.

## Territory Chaos modifications

Territory Chaos adds, among other features:

- versioned custom game rules;
- sandbox/chaos configuration;
- user-uploaded territory skin support;
- WebGL territory image modes;
- social/proximity chat rules;
- storage/state adapters for independent hosting;
- expanded custom multiplayer UI and events.

Add contributors to the fork below as work lands.
